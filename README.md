# Semester-Grade-Tracker
Python coursework that asks the user for the number of classes taken in a previous semester, collects class names, and earned grades.

## FEATURES
1. Dynamic Input: Asks the user how many classes they took last semester.
2. Dictionary Storage: Uses a Python dictionary ('classGrades') to map each class name to its corresponding letter grade.
3. Summary: Loops through the dictionary keys to display a clear breakdown of grades earned for each class.

## HOW TO RUN
1. Open Semester Grade Tracker.py
2. Run the script in the terminal
3. Enter the requested number of classes, class names, and grades when prompted!
